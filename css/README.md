# Portfólio Acadêmico — Gabriel Henrique

Portfólio pessoal desenvolvido em HTML e CSS puros, apresentando minha trajetória acadêmica em Análise e Desenvolvimento de Sistemas (ADS), habilidades, projetos e informações de contato.



## Tecnologias utilizadas

- HTML5 semântico
- CSS3 (variáveis, Flexbox, animações nativas via `@supports`)
- Design responsivo, com suporte a tema claro/escuro automático (`prefers-color-scheme`)

##  Funcionalidades

- Navegação por seções com scroll suave
- Seção "Sobre mim" com foto de perfil
- Lista de habilidades e tecnologias
- Linha do tempo da trajetória acadêmica
- Tabela de projetos desenvolvidos
- Página de contato separada, com formulário e canais diretos (e-mail, LinkedIn, GitHub)
- Barra de progresso de leitura e animações de entrada ao rolar a página

## 🚀 Como executar localmente

```bash
git clone https://github.com/Noluvvvv/portfólio_sobrenome.git
cd portfólio_sobrenome
```

Depois, é só abrir o `index.html` no navegador, ou usar a extensão **Live Server** no VS Code para recarregamento automático.
